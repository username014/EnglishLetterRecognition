# EnglishLetterRecognition
This is a project on the subject of "neural network methods", which is the definition of drawn English letters using a neural network in real time. Within the framework of this project, 63 experiments were implemented for training using various SAT and TTA mechanisms, as well as their combinations. EMNIST Letters and ImprovedLetterCNN were used for correct letter recognition.
